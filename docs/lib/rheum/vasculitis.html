بخش ۱

📄
📋 مقدمه و طبقه‌بندی واسکولیت (Chapel Hill 2012)
واسکولیت = التهاب دیواره عروق که منجر به ایسکمی بافتی، نکروز و آسیب ارگان می‌شود. طبقه‌بندی اصلی بر اساس اندازه عروق درگیر انجام می‌شود (Chapel Hill Consensus 2012).
🔵آرتریت ژانت‌سل (GCA)
  • سن >۵۰ سال
  • سردرد تمپورال جدید
  • کلودیکاسیون فک
  • ESR >۵۰
  • خطر کوری ناگهانی
  • ارتباط با PMR
  • عروق بزرگ
🔵تاکایاسو (Takayasu)
  • سن <۴۰ سال
  • بیماری بدون نبض (Pulseless)
  • اختلاف فشارخون بازوها >۱۰ mmHg
  • درگیری قوس آئورت
  • کلودیکاسیون اندام‌ها
  • زنان آسیایی شرقی
  • عروق بزرگ
🟠پلی‌آرتریت ندوزا (PAN)
  • ارتباط با HBV (~۳۰٪)
  • ریه درگیر نمی‌شود!
  • بدون گلومرولونفریت
  • میکروآنوریسم در آنژیوگرافی
  • ANCA منفی
  • مونونوریت مولتیپلکس
  • عروق متوسط
🟠کاوازاکی (Kawasaki)
  • کودکان <۵ سال
  • تب ≥۵ روز + ۴/۵ معیار
  • آنوریسم کرونری
  • درمان: IVIG + آسپیرین
  • زبان توت‌فرنگی
  • پوسته‌ریزی انگشتان
  • عروق متوسط
🔴GPA (وگنر)
  • c-ANCA (PR3)
  • تریاد: ENT + ریه + کلیه
  • بینی زینی (Saddle nose)
  • ضایعات حفره‌دار ریوی
  • گرانولوم نکروزان
  • گلومرولونفریت هلالی
  • عروق کوچک-ANCA
🔴MPA (میکروسکوپیک)
  • p-ANCA (MPO)
  • سندرم ریوی-کلیوی
  • بدون گرانولوم
  • خونریزی آلوئولی منتشر
  • RPGN (نوع pauci-immune)
  • تفاوت اصلی با PAN: عروق کوچک
  • عروق کوچک-ANCA
🔴EGPA (چرگ-استراوس)
  • آسم + ائوزینوفیلی
  • ائوزینوفیل >۱۵۰۰ یا >۱۰٪
  • p-ANCA مثبت در ~۴۰٪
  • درگیری قلبی = اصلی‌ترین علت مرگ
  • سه فاز: آلرژیک → ائوزینوفیلی → واسکولیت
  • مونونوریت مولتیپلکس
  • عروق کوچک-ANCA
🟢IgA واسکولیت (HSP)
  • شایع‌ترین واسکولیت کودکان
  • تتراد: پورپورا + آرترالژی + درد شکم + GN
  • پورپورای قابل لمس (اندام تحتانی)
  • IgA در IF بیوپسی
  • معمولاً خودمحدود
  • پس از عفونت تنفسی فوقانی
  • عروق کوچک-IC
🟢کرایوگلوبولینمیک
  • ارتباط قوی با HCV
  • پورپورای قابل لمس
  • کمپلمان پایین (خصوصاً C4)
  • نوع II: مونوکلونال + پلی‌کلونال
  • آرترالژی + نوروپاتی
  • فاکتور روماتوئید مثبت
  • عروق کوچک-IC
🟢Anti-GBM (گودپاسچر)
  • آنتی‌بادی ضد کلاژن نوع IV
  • IF: رسوب خطی IgG
  • خونریزی ریوی + GN
  • مردان جوان سیگاری
  • درمان: پلاسمافرز + سیکلوفسفامید
  • GN هلالی نوع I
  • عروق کوچک-IC
🟣بهچت (Behçet)
  • زخم دهانی راجعه (الزامی)
  • زخم تناسلی + اووئیت
  • تست پاترژی مثبت
  • HLA-B51
  • جاده ابریشم (Silk Road)
  • ترومبوز وریدی/شریانی
  • عروق متغیر
🟣کوگان (Cogan)
  • کراتیت بینابینی
  • اختلال شنوایی حسی-عصبی
  • شبیه سندرم منیر
  • آئورتیت
  • بالغین جوان
  • درمان: کورتیکواستروئید
  • عروق متغیر

📊 جدول طبقه‌بندی واسکولیت‌ها (Chapel Hill 2012)
اندازه عروق بیماری ANCA ارگان اصلی نشانه کلیدی سن شایع
بزرگ GCA (ژانت‌سل) منفی شریان تمپورال، آئورت سردرد + کلودیکاسیون فک + کوری >۵۰
تاکایاسو منفی قوس آئورت و شاخه‌ها بی‌نبضی + اختلاف BP بازوها <۴۰
متوسط PAN منفی کلیه، GI، عصبی (نه ریه!) HBV + میکروآنوریسم هر سنی
کاوازاکی منفی عروق کرونری تب ≥۵ روز + آنوریسم کرونری <۵
کوچک (ANCA) GPA (وگنر) c-ANCA (PR3) ENT + ریه + کلیه گرانولوم + حفره ریوی + بینی زینی هر سنی
MPA p-ANCA (MPO) ریه + کلیه سندرم ریوی-کلیوی بدون گرانولوم هر سنی
EGPA p-ANCA (~۴۰٪) ریه + قلب + اعصاب آسم + ائوزینوفیلی + نوروپاتی هر سنی
کوچک (IC) IgA واسکولیت (HSP) منفی پوست + مفاصل + GI + کلیه تتراد HSP در کودکان ۳-۱۰ سال
کرایوگلوبولینمیک منفی پوست + کلیه + اعصاب HCV + پورپورا + C4↓ هر سنی
Anti-GBM منفی ریه + کلیه خونریزی ریوی + GN هلالی خطی مرد جوان
متغیر بهچت منفی دهان + تناسلی + چشم + عروق آفت دهان + پاترژی + HLA-B51 ۲۰-۴۰

بخش ۳

📄
🔵 آرتریت سلول ژانت (Giant Cell Arteritis) — واسکولیت عروق بزرگ
بیوپسی شریان تمپورال = Gold Standard تشخیص GCA
⚡ نکته: وجود Skip Lesions باعث می‌شود بیوپسی منفی کاذب داشته باشیم → نمونه باید حداقل ۲-۳ سانتی‌متر باشد.
⚡ بیوپسی منفی GCA را رد نمی‌کند!
اورژانس چشمی: اگر بیمار علائم بینایی دارد (آمائوروز فوگاکس، دوبینی، کوری ناگهانی) → درمان فوری با متیل‌پردنیزولون IV بدون انتظار برای بیوپسی!
علت کوری: نوروپاتی ایسکمیک قدامی عصب اپتیک (AION)
GCA و PMR اغلب همراه هستند:
• ~۵۰٪ بیماران GCA علائم PMR دارند
• ~۱۵-۲۰٪ بیماران PMR به GCA مبتلا می‌شوند
• در آزمون: اگر PMR به درمان پاسخ ندهد → به GCA فکر کن!
معیارهای ACR برای GCA (۳ از ۵):
۱. سن >۵۰ سال
۲. سردرد جدید
۳. حساسیت شریان تمپورال یا کاهش نبض
۴. ESR >۵۰ mm/h
۵. بیوپسی شریان غیرطبیعی
حساسیت ۹۳٪ | اختصاصیت ۹۱٪
یادآور GCA: پیرزن با سردرد + فک درد + چشم تار + ESR بالا
💊 درمان: پردنیزون ۴۰-۶۰ mg/day
📌 اگر علائم چشمی: متیل‌پردنیزولون ۱ گرم IV × ۳ روز
📌 داروی استروئیداسپارینگ: توسیلیزومب (Tocilizumab) — اولین بیولوژیک تأیید شده برای GCA!

بخش ۴

📄
🔵 آرتریت تاکایاسو (Takayasu Arteritis)
معیارهای ACR (۳ از ۶):
۱. سن شروع <۴۰ سال | ۲. کلودیکاسیون اندام‌ها | ۳. کاهش نبض شریان بازویی | ۴. اختلاف فشار سیستولی >۱۰ mmHg بین دو بازو | ۵. سوفل روی آئورت یا ساب‌کلاوین | ۶. آنژیوگرافی غیرطبیعی
تفاوت GCA و تاکایاسو:
• GCA: >۵۰ سال | تاکایاسو: <۴۰ سال
• GCA: شریان تمپورال | تاکایاسو: آئورت و شاخه‌ها
• هر دو: گرانولوم سلول ژانت در پاتولوژی
• هر دو: ANCA منفی
⚠️ تله: اگر سن بین ۴۰-۵۰ باشد = مرز خاکستری!
تصویربرداری:
• MRA یا CTA = جایگزین آنژیوگرافی تهاجمی
• PET-CT: برای ارزیابی فعالیت بیماری
• یافته: تنگی، انسداد، آنوریسم آئورت
💊 درمان: کورتیکواستروئید + متوترکسات/آزاتیوپرین
📌 موارد مقاوم: توسیلیزومب

بخش ۵

📄
🟠 پلی‌آرتریت ندوزا (Polyarteritis Nodosa)
مهم‌ترین تله آزمون در PAN:
۱. PAN ریه را درگیر نمی‌کند! (اگر ریه درگیر باشد → MPA یا GPA فکر کنید)
۲. PAN گلومرولونفریت ندارد! (درگیری کلیوی از نوع عروقی/ایسکمیک است)
۳. ANCA منفی است! (اگر ANCA+ باشد → MPA فکر کنید)
۴. PAN عروق متوسط را درگیر می‌کند نه عروق کوچک
تشخیص PAN:
• بیوپسی: نکروز فیبرینوئید دیواره عروق متوسط
• آنژیوگرافی مزانتریک: میکروآنوریسم‌ها + تنگی + انسداد (Beading)
• چک HBsAg الزامی!
درمان PAN:
• HBV منفی: کورتیکواستروئید ± سیکلوفسفامید
• HBV مثبت: آنتی‌ویرال + پلاسمافرز (نه سرکوب ایمنی تنها!)
📌 نکته کلیدی: درمان HBV-PAN با ایمونوساپرسیو تنها = اشتباه آزمونی!

بخش ۶

📄
🟠 بیماری کاوازاکی (Kawasaki Disease)
آنوریسم عروق کرونری = عارضه خطرناک و شایع‌ترین علت بیماری قلبی اکتسابی در کودکان کشورهای پیشرفته.
اگر درمان نشود: ~۲۵٪ آنوریسم کرونری ایجاد می‌شود. با درمان IVIG: به <۵٪ کاهش می‌یابد.
معیارهای تشخیصی (تب ≥۵ روز + ۴ از ۵ = CRASH and Burn):
C = Conjunctivitis (کونژنکتیویت دوطرفه غیرچرکی)
R = Rash (بثورات پلی‌مورف)
A = Adenopathy (لنفادنوپاتی سرویکال >۱.۵cm، معمولاً یکطرفه)
S = Strawberry tongue (زبان توت‌فرنگی + لب‌های قرمز ترک‌خورده)
H = Hand/foot changes (ادم + اریتم → پوسته‌ریزی)
💊 درمان: IVIG ۲ g/kg (دوز واحد) + آسپیرین با دوز بالا
📌 در فاز حاد: آسپیرین ضدالتهابی (۸۰-۱۰۰ mg/kg/day)
📌 پس از قطع تب: آسپیرین ضدپلاکتی (۳-۵ mg/kg/day)
⚠️ تله: کاوازاکی یکی از معدود مواردی است که آسپیرین در کودکان تجویز می‌شود!
۷

گرانولوماتوز با پلی‌آنژئیت (GPA = وگنر سابق)

📄
🔴 واسکولیت‌های ANCA-مرتبط (AAV) — بخش کلیدی آزمون
نکته طلایی ANCA:
• c-ANCA = anti-PR3 → بیشتر در GPA (وگنر) → حساسیت ~۹۰٪
• p-ANCA = anti-MPO → بیشتر در MPA و EGPA
⚠️ تله: p-ANCA در بیماری‌های غیرواسکولیتی هم مثبت می‌شود (مثل IBD، هپاتیت اتوایمیون) → فقط anti-MPO اختصاصی است!
درگیری ENT (بالایی)

سینوزیت مزمن مقاوم به درمان

بینی زینی (Saddle nose) از تخریب غضروف

اوتیت مدیای مزمن

تنگی ساب‌گلوتیک

رینوره خونی/چرکی

پرفوراسیون سپتوم بینی

درگیری ریوی (پایینی)

ندول‌ها و حفرات ریوی

ارتشاح ریوی

خونریزی آلوئولی منتشر (DAH)

سرفه + هموپتیزی

پلورال افیوژن

تنگی نایژه

درگیری کلیوی

RPGN (گلومرولونفریت هلالی)

IF: Pauci-immune (بدون رسوب ایمنی)

هماچوری + پروتئینوری

نارسایی کلیوی پیشرونده

بدون درمان → ESRD

تشخیص GPA:
• c-ANCA (anti-PR3) مثبت (~۹۰٪ در فرم فعال)
• بیوپسی: گرانولوم نکروزان + واسکولیت نکروزان
• بیوپسی کلیه: GN هلالی pauci-immune
💊 درمان القایی: سیکلوفسفامید + کورتیکواستروئید یا ریتوکسیمب + کورتیکواستروئید
💊 درمان نگهدارنده: آزاتیوپرین یا ریتوکسیمب

🔺 تفاوت MPA و GPA — سؤال کلاسیک آزمون

ویژگی GPA (وگنر) MPA
ANCA غالب c-ANCA (PR3) p-ANCA (MPO)
گرانولوم دارد ✔️ ندارد ✖️
درگیری ENT شایع و برجسته نادر
حفره ریوی شایع نادر
DAH ممکن شایع‌تر
GN هلالی pauci-immune هلالی pauci-immune
عود شایع‌تر کمتر

🔺 EGPA (چرگ-استراوس) — واسکولیت + آسم + ائوزینوفیل

سه فاز کلاسیک EGPA:
فاز ۱: پرودرومال/آلرژیک → آسم + رینیت آلرژیک (سال‌ها قبل)
فاز ۲: ائوزینوفیلی → ائوزینوفیلی خون + ارتشاح بافتی
فاز ۳: واسکولیتی → واسکولیت سیستمیک
⚠️ اصلی‌ترین علت مرگ: درگیری قلبی (میوکاردیت ائوزینوفیلیک، پریکاردیت)
تله EGPA:
• p-ANCA فقط در ~۴۰٪ مثبت است (بر خلاف MPA که بیشتر مثبت است)
• بیمارانی که ANCA مثبت دارند → بیشتر درگیری کلیوی و عصبی
• بیمارانی که ANCA منفی دارند → بیشتر درگیری قلبی
• ائوزینوفیل >۱۰٪ یا >۱۵۰۰/μL = معیار تشخیصی

📄
🟣 بیماری بهچت (Behçet's Disease)
معیارهای تشخیصی بین‌المللی:
الزامی: زخم دهانی راجعه (≥ ۳ بار در سال) + ۲ از ۴ زیر:
۱. زخم تناسلی راجعه
۲. ضایعات چشمی (اووئیت قدامی/خلفی، واسکولیت رتینال)
۳. ضایعات پوستی (اریتمانودوزوم، فولیکولیت، ضایعات آکنه‌ایفرم)
۴. تست پاترژی مثبت (پاپول ≥۲mm پس از ۲۴-۴۸ ساعت)
نکات آزمونی بهچت:
• HLA-B51 (نه HLA-B27!)
• جاده ابریشم: ترکیه، ایران، ژاپن
• تنها واسکولیت با ترومبوز وریدی و شریانی
• آنوریسم شریان ریوی (علت هموپتیزی ماسیو)
• ⚠️ تله: بهچت = واسکولیت عروق متغیر (نه فقط کوچک!)
نوروبهچت:
• مننگوآنسفالیت

🗺️ الگوریتم تشخیصی واسکولیت — مرحله به مرحله
  1. شک بالینی: تب، ضعف، کاهش وزن + درگیری چند ارگان (پوست، کلیه، ریه، اعصاب)
  2. آزمایشات اولیه: CBC, ESR, CRP, UA, BUN/Cr, LFT, HBsAg, Anti-HCV
  3. آزمایشات اختصاصی: c-ANCA (PR3), p-ANCA (MPO), Anti-GBM, Cryoglobulin, Complement (C3, C4), ANA
  4. تعیین اندازه عروق: بالینی + تصویربرداری (CT/MR آنژیوگرافی برای عروق بزرگ/متوسط)
